# Кадры и калибровка (задача 2)

Здесь лежат артефакты, а не исходники: реальные кадры с камеры БПЛА кладите в
`samples/frames/*.jpg` (папка `samples/` не игнорируется git — не коммитьте
крупные бинарники без необходимости).

## Запуск

```bash
python3 main.py --frame samples/frames/frame_001.jpg \
    --config config/routes.json \
    --debug-out samples/frames/frame_001_annotated.png
```

Машиночитаемый вывод для отчёта:

```bash
python3 main.py --frame samples/frames/frame_001.jpg --json
```

## Что калибровать в первую очередь

1. `hsv_ranges` для каждого цвета в `config/routes.json` — снимайте значения с
   реальных кадров (освещение и баланс белого камеры сильно смещают Hue).
2. `px_per_meter` — масштаб: сколько пикселей приходится на метр на высоте
   полёта. Пока `null`, длина выводится в пикселях.
3. `min_area_px` — минимальная площадь пятна, чтобы шум и блики не считались
   маршрутом.
4. `dangerous` — какой маршрут исключается из выборки. Сейчас это заглушка:
   опасным помечен синий маршрут №3. После получения реального кадра с поля
   проверьте, какой маршрут передан спутником как опасный, и обновите флаг.

## Важно

`config/routes.json` — стартовая палитра-заглушка, а не калибровка под реальную
сцену. Пороговые значения и масштаб нужно перепроверить, как только появятся
кадры с камеры.
