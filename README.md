# Vector2Mars — задача 2

Пайплайн для второго этапа: декодирование снимка со спутника, распознавание
ArUco-меток, поиск маршрутов из стрелок и вывод второго по длине маршрута.
Управление дроном Pioneer Mini 2 вынесено в отдельный слой и после съёмки
автоматически прогоняет свежее фото через тот же детектор.

## Что умеет

- **Декодер JPEG.** Принимает лог приёмника (`спутник бурмалдутник.txt`) и
  собирает из него `image.jpg` — снимок поля.
- **ArUco.** Находит метки `DICT_4X4_50`, возвращает id, центр, углы и сторону
  в пикселях. На тёмных кадрах делает второй проход с CLAHE, чтобы не терять
  мелкие метки.
- **Масштаб.** `px_per_meter` по физическому размеру стороны метки — длина
  маршрута переводится из пикселей в метры.
- **Маршруты из стрелок.** Ищет стрелки по форме (Canny + маски красного и
  синего), связывает их в цепочки графом соседей и привязывает концы цепочки
  к паре меток. Поддержаны белые, красные и синие стрелки разного размера,
  изогнутые маршруты и несколько маршрутов в одном кадре.
- **Второй по длине маршрут.** `second_longest_route` ранжирует найденные
  маршруты и возвращает второй — именно его требует задание.
- **Пульт дрона.** TUI для полёта, фото и журнала; после `P` (фото) кадр
  обрабатывается детектором, а второй маршрут показывается в статусе и
  пишется в JSONL-журнал.

## Структура

| Путь | Назначение |
|---|---|
| `decode_jpeg.py` | декодер лога приёмника → `image.jpg` |
| `mars/aruco.py` | детекция и разметка ArUco-меток |
| `mars/scale.py` | масштаб пикселей в метры по метке |
| `mars/arrow_routes.py` | поиск стрелок, маршрутов, длин и разметка |
| `mars/vision.py` | сегментация цветных маршрутов и длина по скелету |
| `mars/config.py`, `config/routes.json` | палитра HSV и параметры сцены |
| `mars/flight.py`, `mars/drone.py`, `mars/teleop.py` | полётный слой |
| `mars/flightlog.py` | журнал полёта в JSONL |
| `drone_tui.py` | терминальный пульт дрона |
| `main.py` | CLI обработки кадра без железа |
| `samples/` | спутниковый снимок и примеры разметки |
| `tests/` | unittest без железа |

## Установка

```bash
python3 -m pip install -r requirements.txt
```

Для пульта дополнительно:

```bash
python3 -m pip install -r requirements-drone.txt
```

## Быстрый старт

```bash
# лог приёмника → снимок
python3 decode_jpeg.py "спутник бурмалдутник.txt" -o samples/image.jpg

# метки и масштаб
python3 -m mars.aruco samples/image.jpg --out samples/image_markers.png
python3 -m mars.aruco samples/image.jpg --marker-size-m 0.15

# маршруты и разметка
python3 -m mars.arrow_routes samples/image.jpg --out samples/image_route.png

# обработка кадра без железа
python3 main.py --frame samples/image.jpg --json
```

## Результаты на примерах

Спутниковый снимок `samples/image.jpg` (347×446), метки `0` и `2`:

|---|---|---|
| `0 → 2` | 3 (белые) | 139.8 px |

Полевой кадр 1920×2560, метки `0, 2, 3, 4`:

|---|---|---|
| `0 → 4` | 13 (7 красных, 6 белых) | 2302.1 px |
| `0 → 3` | 8 (белые) | 1189.7 px |
| `0 → 2` | 3 (2 синие, 1 белая) | 645.7 px |

Второй по длине здесь — `0 → 3`.

## Пульт дрона

```bash
python3 drone_tui.py --dry-run   # интерфейс без железа
python3 drone_tui.py             # ноутбук в Wi-Fi дрона
python3 drone_tui.py --local     # запуск на борту
```

Клавиша `P` сохраняет фото в `photos/`, после чего детектор считает маршруты.
В статусе появляется второй по длине маршрут, а полный список уходит в
JSONL-журнал событием `routes`. Подробности — `docs/drone-tui.md`.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

Все тесты офлайн: синтетические кадры, снимок из `samples/` и заглушки
вместо SDK, поэтому железо для проверки не нужно.

## Ограничения

- Пороги детектора адаптируются к яркости кадра, но при сильном пересвете
  белые стрелки на светлом полу могут пропадать.
- Если метка не распознана, две соседние цепочки могут слиться в один
  маршрут; детектор ArUco делает дополнительный проход, чтобы этого избежать.
- Длина считается по центрам стрелок, а не по длине нарисованной линии.
